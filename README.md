# 🎮 Super Mario Style Game

A fun and interactive browser-based platform game built using **HTML, CSS, and JavaScript**.

## 📖 About the Project

This project is a 2D platform game inspired by classic platform games. The player controls a character, moves through platforms, avoids obstacles, collects items, and tries to achieve the highest score.

The game was developed using web technologies without any external game engine.

## ✨ Features

* 🎮 Player movement
* 🏃 Left and right movement
* 🦘 Jump mechanics
* 🪙 Coin collection
* 👾 Enemy obstacles
* ❤️ Lives system
* 🏆 Score system
* 🌍 Platform-based levels
* 🎨 Animated game environment
* 🔊 Sound effects

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **HTML Canvas**

## 🎮 Controls

| Key            | Action     |
| -------------- | ---------- |
| ⬅️ Left Arrow  | Move Left  |
| ➡️ Right Arrow | Move Right |
| ⬆️ Up Arrow    | Jump       |
| Space          | Jump       |

## ▶️ How to Play

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Use the keyboard controls to move the player.
5. Collect coins and avoid enemies.
6. Try to achieve the highest score.
