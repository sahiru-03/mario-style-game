# 🎮 Pixel Quest

A 2D browser platformer built entirely with HTML, CSS and JavaScript.

## 🎮 Features

- Player movement
- Jumping and gravity
- Platform collision
- Enemy AI
- Coin collection
- Score system
- Lives system
- Camera scrolling
- Level goal
- Game over screen
- Win screen
- Responsive design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas

## 🎮 Controls

| Key   | Action     |
| ----- | ---------- |
| ←     | Move left  |
| →     | Move right |
| A     | Move left  |
| D     | Move right |
| Space | Jump       |
| W     | Jump       |
